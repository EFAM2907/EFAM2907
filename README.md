### 🚀 Featured project

#### [🤖 AI Agent Platform](https://github.com/EFAM2907/ai-agent-platform)

Multi-tenant AI agent platform with tool calling, RAG and Gmail integration. The reference tenant is a courier and logistics company.

- **Conversational agent** with SSE streaming that answers from the company knowledge base (RAG with **pgvector**) and queries or updates shipments and users
- **Strict multi-tenant isolation** with RBAC (`OWNER > ADMIN > MEMBER > VIEWER`), enforced in both the REST API and the chat tools
- **Self-hosted LLM gateway (LiteLLM)** with cost-based model routing, provider fallback, retries and per-tenant budgets, plus **Langfuse** tracing
- **Gmail integration** (OAuth per organization) that auto-answers tracking questions by email
- **Eval harness** for model-routing decisions and ~200 pytest tests against a real Postgres database

`FastAPI` `SQLAlchemy 2.0 async` `PostgreSQL + pgvector` `Redis` `LiteLLM` `Langfuse` `React + TypeScript` `Docker Compose`
